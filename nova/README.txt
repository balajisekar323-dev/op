DEPLOYMENT FOLDER

This is a static HTML file-download website.

Main file:
index.html

Folders:
css/       - stylesheet
files/     - 12 PHP files

There is no PHP login and no download.php dependency.
Each Down button points directly to files/<filename>.php, so the site can be deployed on static hosting.

Deploy/upload the CONTENTS of this folder so that index.html is at the hosting site's public/root directory.
